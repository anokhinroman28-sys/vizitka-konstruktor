# Визитка JSON — HTML-редактор + рабочий QR

## Контекст
Доводил до ума HTML-страницу «визитка в стиле JSON-редактора» (предпросмотр + экспорт PNG для печати 90×50 мм и digital 1:1). Основная боль — QR-код: несколько итераций он либо не отображался, либо не сканировался. Здесь — что именно ломалось и какое решение оказалось рабочим. Сохраняю как чеклист на будущее, чтобы не повторять цикл проб.

## Что ломало QR (по порядку грабель)

| Версия | Что делал | Почему не работало |
|---|---|---|
| v1–v3 | `qrcodejs`, голубые модули на тёмном фоне | Светлые модули совпадали по цвету с фоном карты, нет тихой зоны → нет контраста, сканер слеп |
| v4 | Самописный кодировщик QR | Reed-Solomon с ошибкой → код невалиден в принципе |
| v5 | `qrcodejs`, ч/б, уровень коррекции `H` | `H` = плотная сетка 33×33, модули < 2px → мыло; `html2canvas` ломает `<canvas>` при экспорте |
| v7 | `node-qrcode` с **jsdelivr** | *Песочница предпросмотра claude.ai блокирует jsdelivr* → `QRCode is not defined` |
| **v8–v9** | `qrcode-generator` **вшита в файл**, рендер в `<img>` | **Рабочий вариант** |

## Рабочее решение

1. **Библиотека `qrcode-generator`** (Kazuhiko Arase, MIT) — вшита прямо в HTML, без CDN. Глобальная функция `qrcode(0, 'M')`.
2. **Уровень коррекции `M`** — сетка 25×25, крупные модули, хорошо сканируется в малом размере.
3. **Рендер в `<img>` через `canvas.toDataURL()`**, а не голый `<canvas>` — `html2canvas` корректно копирует картинки, но мнёт canvas.
4. **Тихая зона ≥ 4 модуля** + высокий контраст обязательны.
5. **Проверка валидности — round-trip тестом в node**: генерация → расшифровка через `jsqr` → сверка текста. Не «на глаз».

## Ключевые ограничения среды

> ℹ️ **CDN:** в предпросмотре HTML-артефактов claude.ai внешние скрипты грузятся только с `cdnjs.cloudflare.com`. `jsdelivr` / `unpkg` — блокируются. Надёжнее вшивать библиотеку.

> ⚠️ **Инверсия QR:** белые модули на тёмном фоне читают только сканеры с поддержкой инверсии (современные телефоны — да, старые/дешёвые — нет). Чёрное-на-белом — универсально. Round-trip это подтвердил: `dontInvert` режим на белом-по-тёмному = FAIL.

## Что в финальном файле (`vizitka_v9.html`)
- Левая панель: name, tagline, контакты, выбор шрифта (5 моноширинных с кириллицей), 5 цветовых тем, редактируемое имя файла в titlebar.
- Две превью-карты: печать 636×354 (=90×50 мм) и digital 540×540.
- Экспорт PNG через `html2canvas` (scale 3 → ~538 dpi).
- QR: белые модули на прозрачном фоне, фон карты = тихая зона; цвет модулей адаптируется под тему.
